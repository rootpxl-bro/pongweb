## About

A two-player pong game in the browser with score display.

## Features

- Pure HTML, CSS and JavaScript
- Responsive dark design with gradient accents
- No build tools, no dependencies
- Easy to host anywhere

## Install

```bash
git clone https://github.com/rootpxl-bro/pongweb.git
cd pongweb
```

## Usage

```bash
open index.html
```
