Quick start

$ git clone <repo-url>
$ cd pongweb
$ open index.html

Layout

Everything lives in the project root. The main page is index.html. Styling lives in styles.css and small helpers in app.js.

Customizing

Change the colors in the CSS variables at the top of styles.css. Add pages as new HTML files and link them from the header.

Deploying

Upload the folder to any static host, or open it directly from disk. No build step required.
